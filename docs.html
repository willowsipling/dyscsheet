Getting started

The sheet is graph paper: every number, letter or symbol gets its own box, so things stay lined up. Click a box (or use the arrow keys) and type.

  • Number rows are for maths. Press Enter to start a new one.
  • Text rows are for words, like notes to yourself about what a step means.
  • Your work saves in this browser by itself. Use Save file to keep a copy on your computer.

The toolbar

Point at any button, or tab to it with the keyboard, and the strip under the toolbar says what it does and its shortcut. When the cursor is on a symbol in your work, the strip says what that symbol means.

File
Start a new sheet, open or save a file, print, and show the finished LaTeX/MathJax version of your work.
Edit
Undo, redo, cut, copy, paste, and zoom the grid.
Wrap
Roots, fractions, parentheses, exponents, subscripts, bars, hats and highlights. See Using the wrap tools.
Symbols
Greek letters and maths signs. Click one to type it at the cursor. The reference card lists what each one means.
Sheet
Add rows above and below, and columns left and right, laid out the way they'll appear around the cursor.

Using the wrap tools

There are two ways to use a wrap tool:

  1. Select the cells first (drag across them, or hold Shift and use the arrow keys), then press the tool.
  2. Press the tool first, then drag across the cells you want it around.

When the cursor is inside a wrap, it's listed under the strip. Press the ✕ on it to take the wrap off. What's inside stays.

Making room inside a root or fraction

  1. Type the extra bits you want to add to the end of the root. Then select by dragging from the start of the root, and press the root button. This extends the root instead of making a double root.
  2. Using "Add Column Left/Right" from inside the root also extends the root.

Tidy fraction

If you copy a fraction from the line above and change parts of it, it can end up with leftover blank spaces or a fraction bar that's too long. Select the junk cells of the leftover fraction, then press Tidy fraction in the Wrap panel (right after the fraction button). You may have to make judicious use of Undo lol.

Note: it can't tidy a fraction that has another fraction in its top. Sorry!

LaTeX/MathJax output and Obsidian

Tick Render LaTeX/MathJax Output in the File panel to see your work as finished, typeset maths below the sheet. Drag the bar at the top of that panel to make it taller or shorter.

Tick Show Obsidian-Friendly MathJax code in that panel to get code you can paste straight into Obsidian. You'll need to put double $$ around it.
