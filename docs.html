Getting started

The sheet is graph paper: every number, letter or symbol gets its own box, so things stay lined up. Click a box (or use the arrow keys) and type.

  • Number rows are for maths. Press Enter to start a new one.
  • Text rows are for words, like notes to yourself about what a step means.
  • Your work saves in this browser by itself. Use Save file to keep a copy on your computer.

The toolbar

Point at any button, or tab to it with the keyboard, and the strip under the toolbar says what it does and its shortcut. When the cursor is on a symbol in your work, the strip says what that symbol means.

File, Edit and View are menus at the top, next to the name, like in a Mac app. Click one (or tab to it and press the down arrow) to open it. Each item shows its shortcut on the right.

File menu
Start a new sheet, open or save a file, and print.
Edit menu
Undo, redo, cut, copy and paste, and Duplicate Line. See Showing your work step by step.
View menu
Show the finished LaTeX/MathJax version of your work, and zoom the grid.
Wrap
Roots, fractions, exponents, subscripts, bars, hats and highlights. See Using the wrap tools.
Symbols
Greek letters and maths signs. Click one to type it at the cursor. The reference card lists what each one means.
Sheet
Add rows above and below the cursor's line, and columns to its left and right.

Using the wrap tools

There are two ways to use a wrap tool:

  1. Select the cells first (drag across them, or hold Shift and use the arrow keys), then press the tool.
  2. Press the tool first, then drag across the cells you want it around.

When the cursor is inside a wrap, it's listed in the Wrap panel, under the buttons. Press the ✕ on it to take the wrap off. What's inside stays.

Making room inside a root or fraction

  1. Type the extra bits you want to add to the end of the root. Then select by dragging from the start of the root, and press the root button. This extends the root instead of making a double root.
  2. Using "Add Column Left/Right" from inside the root also extends the root.

Tidy fraction

If you copy a fraction from the line above and change parts of it, it can end up with leftover blank spaces or a fraction bar that's too long. Select the junk cells of the leftover fraction, then press Tidy fraction in the Wrap panel (right after the fraction button). You may have to make judicious use of Undo lol.

Note: it can't tidy a fraction that has another fraction in its top. Sorry!

Showing your work step by step

  1. Write the formula on a line.
  2. Press Duplicate Line in the Edit menu (or Option+D). The line is copied just below, with the cursor in the same place.
  3. Change one thing on the new line, like putting in a number, then highlight what you changed.
  4. Repeat until you have your answer.

The copy leaves your highlights behind, so each line only highlights its own change.

LaTeX/MathJax output and Obsidian

Tick Render LaTeX/MathJax Output in the View menu to see your work as finished, typeset maths below the sheet. Drag the bar at the top of that panel to make it taller or shorter.

Tick Show Obsidian-Friendly MathJax code in that panel to get code you can paste straight into Obsidian. You'll need to put double $$ around it.

Crosstabs

The Crosstabs page is a crosstab to fill in, for things like a chi-square test. Each box is labelled with what goes in it (fo, %, fe, χ² part, row margin, column margin, n), but nothing is worked out for you. Do the working out on the worksheet.

  • Stacked cells keeps every number about a cell together in that cell. Matched tables gives each quantity its own table, all the same shape.
  • Tick which quantities to show. You can start with just fo and add more as you go. Hiding one doesn't delete what you typed.
  • Set the number of rows and columns (2 to 6) in the toolbar. Name them in the table; names update everywhere.
  • The row and column around the box you're in light up. In matched tables, the same cell lights up in every table.
  • Crosstabs save in their own file, separate from your worksheet.
