How to use dyscsheet

Typing

  • Click a cell, then type. Each cell holds one thing.
  • ← → ↑ ↓ move, including into a fraction's bottom row.
  • Enter starts a new line. Backspace clears the cell in the box. If that cell is already empty, it steps left and clears that one.
  • ⌘C ⌘X ⌘V copy, cut and paste selected cells, wraps included. Pasting pushes the rest of the line right.
  • Space puts a visible gap (␣) in the math. Arrow past a cell to leave it empty.
  • Add column left / Add column right put an empty column beside the cursor cell and push the rest of the line right, so you can fit in something you missed. Shift+Space does the same as Add column left. Option+Backspace removes the column to the left of the cursor.

Wrapping

  • Click a tool, then drag over cells. Or drag first, then click the tool.
  • Fractions: wrap the top. A new row opens underneath for the bottom. Type past its end and the fraction grows.
  • Already typed it as a/b? Wrap the whole thing and the bottom drops down a row.
  • Exponents: wrap just the cells that go up high (the 2 in s²).
  • Keyboard: Shift+arrows to select, then Option+the tool's letter (below).
  • Clearing the last thing inside a wrap removes the wrap too. A fraction goes once both its top and bottom are empty.
  • To undo a wrap, click a cell inside it and press its ✕ in the bar above the sheet, or apply the same tool to the same cells.

Notes

  • New note (Option+N) adds a line of plain text to explain a step. Arrow keys move in and out of it.

Your work

  • Saves automatically in this browser. Save file keeps a copy you can open anywhere.
  • Print / PDF prints the grid. Turn on Finished math to print that too.
  • Drag the handle above the bottom panel to resize it. Click a line there to jump to it.
  • Zoom − and + make the grid smaller or bigger (50% to 200%). Click the percentage to go back to 100%. Only the grid changes size, not the toolbar or the finished math. Zoom also changes how big the grid prints.
  • If a line is wider than the paper, printing shrinks the whole page to fit.
